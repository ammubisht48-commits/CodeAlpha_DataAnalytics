CodeAlpha Data Analytics Internship

Project: Exploratory Data Analysis (EDA)

About the Project

This project performs Exploratory Data Analysis (EDA) on a sample sales dataset using Python.

Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

Dataset

The dataset "sales_data.csv" contains sample sales information, including product, category, quantity, price, month, and sales.

Analysis Performed

- Viewed the dataset and its structure
- Checked data types and summary statistics
- Checked missing values and duplicate records
- Analyzed sales data
- Created visualizations to understand sales patterns

Files Included

- "CodeAlpha_EDA.ipynb" — Jupyter Notebook containing the analysis
- "sales_data.csv" — Sample sales dataset

Conclusion

This project demonstrates basic data cleaning, data exploration, summary statistics, and data visualization using Python.
