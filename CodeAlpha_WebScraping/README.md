CodeAlpha Task 3: Web Scraping

Project Overview

This project demonstrates web scraping using Python to collect book information from a demo website.

Tools and Libraries

- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib

Dataset

The dataset contains:

- Book Name
- Price
- Rating

Project Workflow

1. Fetched website data using Requests.
2. Extracted book names, prices, and ratings using BeautifulSoup.
3. Organized the data using Pandas.
4. Saved the dataset as "books_dataset.csv".
5. Created a bar chart to compare book prices.

Files

- "CodeAlpha_Web_Scraping.ipynb" — Python code and output.
- "books_dataset.csv" — Scraped book dataset.

Conclusion

This project helped me learn web scraping, data collection, data processing, and data visualization using Python.
